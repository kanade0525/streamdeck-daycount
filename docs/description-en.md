Day Count puts a date on a Stream Deck key and keeps the number up to date for you. Choose a date ahead and the key counts down the days to it. Choose one that has passed and the key counts the days since. There is nothing else to set up: no account, no API key, no permission to grant. Pick a date and the key does the rest from then on.

## Two actions

| | What it does |
| --- | --- |
| **Days until** | Counts down to the date. Turns amber as the date gets close |
| **Days since** | Counts up from the date, for anything you want to keep a run going on |

Each one only offers dates that make sense for it — a date ahead for **Days until**, today or
earlier for **Days since** — so a key can never end up showing a number that means nothing.

## Count every day, or only work days

Set a key to skip weekends and it counts work days instead. Switch on the holiday option and
it skips Japanese public holidays too, worked out on your own machine — nothing is downloaded
and no list needs updating each year. The unit text changes to `WORK DAYS LEFT` so the two
kinds of number are never confused for one another.

## Start again from today

Hold a **Days since** key for two seconds and the count starts over from today. This is meant
for a board like days-without-an-incident: when one happens, hold the key and it resets on the
spot, without opening any settings. A bar fills while you hold, so letting go cancels it, and a
short press never does anything. You can switch the whole thing off.

## Reading the key

- **Blue** — the date is still some way off
- **Amber** — the date is close. You choose how many days count as close; seven by default
- **Green** — today is the day, or the key is counting up from a past date
- **Grey** — a **Days until** date that has already gone by

Give a key its own label and it appears above the number. The unit text underneath follows the
state on its own, or you can write your own — useful for a board that should simply read
`NO INCIDENT`.

## Setting it up

1. Drop **Days until** or **Days since** on a key
2. Pick the date
3. That is it

As you pick, the settings panel tells you what the key will show — 42 days left, 127 days so
far — so a mistake is visible before you leave. Several keys can count different dates at once,
each with its own label.

## What it counts

Whole days on the calendar, not hours. A date one minute after midnight tomorrow is one day
away, not zero. Leap years, month ends and daylight saving changes are all handled, so the
number never shifts by a day for the wrong reason.

## What it does not do

It subtracts two dates and draws the result. It does not read your calendar, it does not ask
for any permission, and it makes no network connections at all.

## Requirements

macOS 12 or later, Stream Deck 6.9 or later. Works on keys.
