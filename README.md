# Day Count for Stream Deck

**任意の日付までの残り日数**と、**その日からの経過日数**をキーに出します。

```
┌──────────┐    ┌──────────┐
│ リリース   │    │ 第二工場  │
│    42     │    │   127    │
│ DAYS LEFT │    │  無事故   │
└──────────┘    └──────────┘
```

## なぜ作ったか

Marketplace のカウントダウン系は、**無料のものが全部「時間のタイマー」か
「カレンダー連動」**でした。任意の日付を入れて数えるものは有料しかありません
（Event Countdown $3.99、Time Counter 約$5.3）。

実際に無料のものを入れて触った結果、用途が違うことを確かめたうえで作っています。

## 2つのアクション

| | 何をするか |
| --- | --- |
| **Days until** | 指定した日までの残り日数。期限が近づくと琥珀色になる |
| **Days since** | 指定した日からの経過日数。「無事故◯日」はこちら |

設定するのは**日付だけ**です。キーに出す名前と単位の文字は任意で変えられます。

## 使い方

1. キーに **Days until** か **Days since** を置く
2. 日付を入れる（`2026-03-01` の形）
3. それだけ

日付を入れると、**保存する前に「42日後です」と設定画面に出ます。**

| 欄 | 既定 |
| --- | --- |
| 日付 | （空） |
| キーに出す名前 | （空。空なら数字だけ） |
| 単位の文字 | 空なら状態に合わせて `DAYS LEFT` / `DAYS AGO` / `TODAY` |
| 何日前から色を変えるか | 7（**Days until** のみ） |

## 色

| 色 | 意味 |
| --- | --- |
| 青 | まだ先 |
| 琥珀 | 期限が近い（既定は7日以内） |
| 緑 | 当日、または経過を数えている |
| 灰 | 過ぎた（Days until の場合） |

## 通信しません

日付の引き算だけです。**ネットワークにも、カレンダーにも、他のアプリにもつなぎません。**
権限も要りません。

## 要るもの

- macOS 12 以降
- Stream Deck 6.9 以降（ボタンのみの機種で動きます）

## 入れる

```sh
git clone https://github.com/kanade0525/streamdeck-daycount.git
cd streamdeck-daycount
npm run link
```

Stream Deck を再起動してください。
[Releases](https://github.com/kanade0525/streamdeck-daycount/releases) の
`.streamDeckPlugin` からも入れられます。

## 開発

```sh
npm test       # 日数の勘定の検査（依存パッケージ不要）
npm run preview  # 全状態を実寸で書き出して目で見る
npm run link
npm run pack
```

日数の勘定は間違えても一見それらしく動くので、境目を厚く検査しています。

- 同じ日なら、時刻が違っても0日
- 日をまたげば、2分しか離れていなくても1日
- うるう年、月またぎ、年またぎ
- 夏時間で1日ずれない（両端を正午に寄せてから引く）

## 既知の制約

- macOS のみ。日付の引き算だけなので Windows でも動くはずですが、
  実機で確かめていないので対応として申告していません
- 署名していません。手元でビルドすれば問題ありません
